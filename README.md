# Enhancement of the Image

A MATLAB-based image enhancement project focused on improving image quality using different image processing techniques such as contrast enhancement, filtering, sharpening, histogram equalization, and noise reduction.

## Overview

This project demonstrates various digital image enhancement techniques implemented in MATLAB. The objective is to improve the visual appearance of images and enhance important features for better analysis and interpretation.

The project includes:
- Image contrast enhancement
- Histogram equalization
- Noise removal
- Image sharpening
- Brightness adjustment
- Filtering techniques
- Edge enhancement

## Technologies Used

- MATLAB
- Image Processing Toolbox

## Features

- Improve low-quality images
- Reduce noise from images
- Enhance image contrast
- Apply different filters
- Compare original and enhanced images
- Visualize histogram transformations
